# VIBLO-MSG 💬

موقع محادثات فوري بواجهة احترافية مستوحاة من واتساب، بالعربية واتجاه RTL.

## المميزات

- 🔐 **حساب حقيقي**: إنشاء حساب بالاسم + يوزر فريد + كلمة مرور، وتسجيل الدخول باليوزر وكلمة المرور.
- 🆔 **يوزر فريد** لكل مستخدم مع التحقق المباشر من التوفّر أثناء الكتابة.
- 🔒 كلمات المرور تُخزَّن **مُشفَّرة** (scrypt + salt) ولا تُحفظ كنص صريح، مع حماية من محاولات الدخول المتكررة.
- 🔎 **بحث عن اليوزر** وإرسال **طلب محادثة**.
- ✅ **قبول / رفض الطلبات** من الطرف الآخر (لا يمكن مراسلة أحد قبل موافقته).
- 💬 محادثات فورية عبر Socket.IO مع مؤشر «يكتب الآن»، إشعارات القراءة ✓✓، وعدّاد الرسائل غير المقروءة.
- 😀 إرسال **إيموجيات** من لوحة إيموجي مدمجة.
- 🖼️ إرسال **صور** و 🎬 **فيديو** مع معاينة وعارض (Lightbox) وتحميل.
- 📞 **مكالمات صوتية** و 🎥 **مكالمات فيديو** بين الطرفين عبر WebRTC.
- 🌙 واجهة داكنة، متجاوبة بالكامل مع الجوال، وبدون أي مكتبات واجهة ثقيلة.

## التشغيل السريع

```bash
cd viblo-msg
npm install
npm start
```

ثم افتح: **http://localhost:3000**

أو انقر مرتين على `start.bat` في ويندوز.

> لإنشاء حساب: افتح الموقع، اختر «إنشاء حساب»، واكتب الاسم واليوزر وكلمة المرور. لتجربة محادثة ومكالمة بين حسابين: افتح نافذة تصفح عادية وأخرى خفيّة (Incognito)، وأنشئ حساباً مختلفاً في كل نافذة، ثم ابحث عن يوزر الحساب الآخر وأرسل طلب محادثة.

## الحساب والأمان

- الاسم (اللقب): من حرفين إلى 40 حرفاً.
- اليوزر: من 3 إلى 20 حرفاً، بالإنجليزية والأرقام و `.` أو `_` فقط، ويجب أن يكون فريداً.
- كلمة المرور: 8 أحرف على الأقل.
- الجلسة صالحة لمدة 30 يوماً، ويمكنك تسجيل الخروج من القائمة الشخصية.
- بعد 10 محاولات دخول خاطئة لنفس الحساب يُوقَف الدخول مؤقتاً 15 دقيقة.

## النشر على الإنترنت

راجع **[DEPLOY.md](DEPLOY.md)** لنشر الموقع مجاناً على Render مع رابط دائم وHTTPS.

## ملاحظات

- الملفات المرفوعة تُحفظ في `public/uploads` وقاعدة البيانات في `data/db.json`.
- الحد الأقصى لحجم الملف: 80 ميجابايت.
- المكالمات تستخدم WebRTC مباشرة بين المتصفحين، وتعمل على `localhost` أو HTTPS (شرط المتصفح للوصول للكاميرا والميكروفون). عند النشر على الإنترنت استخدم HTTPS.
- يمكن تغيير المنفذ عبر `PORT`، وإضافة خادم TURN للمكالمات عبر متغيرات `TURN_URL` و`TURN_USERNAME` و`TURN_CREDENTIAL`.
- **لا تشارك ملف `data/secret.txt`** — لأنه يُستخدم لتوقيع جلسات الدخول.
